# GymApp — тренировки в зале

Приложение для тренажёрного зала: всё в одном файле `index.html`, плюс файлы для установки на телефон (`manifest.webmanifest`, `sw.js`, `icons/`). Это PWA: его можно установить на экран «Домой» на iPhone и Android, и после первого открытия оно работает **без интернета**.

## Как открыть на iPhone

На iPhone `.html`-файл из «Файлов» или мессенджера открывается в режиме предпросмотра без JavaScript — поэтому приложение нужно открыть **по ссылке** (https).

1. Опубликуй папку как сайт, например через GitHub Pages: *Settings → Pages → Build and deployment → Deploy from a branch*, выбери ветку и папку `/ (root)`. Для приватного репозитория Pages доступен только на платном тарифе GitHub — либо сделай репозиторий публичным, либо перетащи папку на [app.netlify.com/drop](https://app.netlify.com/drop) или в Cloudflare Pages.
2. Открой полученную ссылку в **Safari** → «Поделиться» → **«На экран „Домой“»**.
3. Запусти GymApp с иконки — всё сохранится на устройстве и будет работать без сети. Обновления подтягиваются сами при следующем запуске с интернетом.

## Что внутри

- **54 упражнения** с анимацией выполнения (рабочие мышцы подсвечены оранжевым), пошаговой техникой, частыми ошибками и советами. Все упражнения из программы для начинающих перенесены дословно.
- **Программы**: готовые «Тренировка А» и «Тренировка Б» из PDF (с разминкой), а также «Тренировка В · штанга» и «Без тренажёров». Можно создавать свои программы, менять подходы, повторения, отдых и порядок упражнений.
- **Режим тренировки**: общий таймер, отметка подходов (вес × повторы, время, минуты), автотаймер отдыха со звуком и вибрацией, секундомер для планки и кардио, результаты прошлой тренировки и подсказка по «двойной прогрессии» — когда пора добавлять вес. У каждого упражнения есть аналоги (если тренажёр занят или хочется проще/сложнее) — их можно выбрать прямо во время тренировки. Экран не гаснет во время тренировки (где браузер это поддерживает).
- **Статистика**: тренировки и тоннаж по неделям, прогресс в каждом упражнении (макс. вес, оценка 1ПМ, объём), подходы по группам мышц, календарь активности, личные рекорды и история.
- **Гид для новичка**: расписание, подбор веса, отдых, темп, прогрессия, разминка, заминка, техника безопасности.

Данные хранятся в `localStorage` браузера. В «Настройках» есть экспорт и импорт резервной копии (JSON).
